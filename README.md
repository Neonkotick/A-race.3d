# A-race.3d

Neon Grid endless runner (Tron style).

## Play
Open index.html or GitHub Pages: https://neonkotick.github.io/A-race.3d/

## Controls
Swipe left/right — lanes. Collect crystals, boost, purple shield (2x speed + DEREZ).

## Telegram Mini App
1. Enable GitHub Pages (Settings → Pages → Deploy from branch main / root)
2. @BotFather → /newbot
3. /newapp or /setmenubutton → paste Pages HTTPS URL
4. Play via https://t.me/BOT/APP
